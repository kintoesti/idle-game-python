# Idle Game Python 🍪

Un simple jeu inactif (Idle Game) développé en Python.

## 📖 Description

Un jeu où tu cliques pour gagner des points, et achètes des générateurs automatiques qui produisent des points sans action.

## 🎮 Mécaniques

- **Cliquer** (appuyer sur ESPACE) pour gagner des points
- **Acheter** des générateurs automatiques
- **Upgrades** pour améliorer la production
- **Sauvegarde** automatique de la progression

## 🚀 Installation

```bash
python idle_game.py
```
